# Sugar Cosmetics Instagram Analytics — Tableau

## Project Overview

This project analyzes Sugar Cosmetics' Instagram content performance to understand post volume, reach, likes, comments, engagement, and content performance trends.

The objective is to identify patterns in social media engagement and generate data-driven recommendations for improving content performance.

## Tools & Technologies

- Tableau
- Excel
- Data Visualization
- Exploratory Data Analysis

## Key KPIs

- Total Posts: 50,000
- Total Reach: 987,423,288
- Total Likes: 147,288,279
- Total Comments: 18,459,361
- Average Engagement Score: 18.5

## Analysis Performed

The dashboard analyzes:

- Monthly post trends
- Top posts by likes
- Engagement rate
- Average engagement by weekday
- Instagram content funnel
- Overall social media KPIs

## Monthly Analysis

The project analyzes Instagram activity across the available period, including monthly post trends.

April 2024 and April 2025 contain comparatively lower/partial records and should be interpreted carefully when comparing monthly activity.

## Tableau Dashboard

The dashboard includes:

1. KPI Overview
2. Monthly Trend
3. Top 10 Posts by Likes
4. Engagement Rate Analysis
5. Weekday Engagement Analysis
6. Instagram Funnel

## Key Skills Demonstrated

- Tableau
- Data Visualization
- KPI Analysis
- Trend Analysis
- Engagement Analysis
- Business Recommendations
- Dashboard Design


## Business Recommendations

Based on the analysis, businesses can:

- Identify high-performing content patterns
- Optimize posting schedules
- Focus on content generating stronger engagement
- Monitor engagement trends over time
- Use top-performing posts as benchmarks for future campaigns

## Conclusion

The project demonstrates how Tableau can be used to transform social media data into actionable insights for marketing and content strategy.
